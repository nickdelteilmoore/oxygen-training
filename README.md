**Oxygen 101 – Medical Oxygen Training**

This repository hosts the Oxygen 101 e-learning course, produced by the Oxygen CoLab. The course provides an accessible introduction to medical oxygen — covering how it is produced, stored, and delivered in health facility settings — and is designed for health workers, programme staff, and others working in low- and middle-income country contexts.


**About the Oxygen CoLab**

The Oxygen CoLab is a FCDO-funded programme supporting innovation and systems change in medical oxygen access across sub-Saharan Africa and South Asia. Managed by DT Global UK, the programme works with a portfolio of grantees developing technologies, tools, and approaches to improve the availability and reliability of medical oxygen in health facilities. Oxygen 101 was developed as part of the programme's knowledge-sharing and capacity-building work.


**About this repository**

The course is built in Articulate Rise and exported as a static web package, served via GitHub Pages and embedded on the Oxygen CoLab Website.

Live URL: http://makingbetterfutures.org/oxygen-101

No LMS is used — there is no completion tracking or user data collection.
Hosting the course yourself
If you would like to host this course on your own LMS or website, a SCORM-compatible version is available on request. Please contact the Oxygen CoLab team to obtain a copy. The course can be deployed on any SCORM 1.2 or SCORM 2004-compliant platform.
