**Oxygen 101 – Medical Oxygen Training**

This repository hosts the Oxygen 101 e-learning course, produced by Oxygen CoLab. The course is built in Articulate Rise and exported as a web package, served via GitHub Pages and embedded on the Oxygen CoLab Squarespace site.
Live URL: https://nickdelteilmoore.github.io/oxygen-training/

**How it works**
The course files are static HTML/CSS/JS assets exported from Rise. GitHub Pages serves them as a public website, which is then embedded in Squarespace via an <iframe> at 1000px height.
No LMS is used — there is no completion tracking or user data collection.

**Updating the course**
Export the updated course from Articulate Rise as Web (not SCORM)
Go to Add file → Upload files in this repository
Drag in all contents of the unzipped export folder (this will overwrite existing files)
Click Commit changes
Wait ~90 seconds for GitHub Pages to rebuild, then hard-refresh the live URL to verify

The Squarespace embed does not need updating — it uses the same URL.

**Repository visibility**
This repository is public. The course content is openly accessible at the GitHub Pages URL. The Squarespace page may apply additional access controls (e.g. password protection) as needed.
